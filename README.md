# Capstone Backend

Repository ini menyiapkan source backend Capstone Project sebagai proyek terpisah untuk tugas individu Dockerisasi Backend. 

## Isi proyek

- Backend Node.js, Express, dan TypeScript
- PostgreSQL dengan Drizzle ORM
- Skema dan migrasi database di `src/db/schemas` dan `migrations/`
- Dokumentasi endpoint di [`api.specs.md`](api.specs.md)
